# Canvas Desk artwork

All assets are original pixel art generated by `tools/generate-assets.py`, which is the editable source. Run it with Python 3, Pillow and NumPy. NumPy is used only for the authoring preview depth buffer. The generator uses a fixed local random seed and has no network or downloaded-art dependency. PNGs are game resources; `art/source/` contains pixel-preserving SVG versions editable in vector tools. The actual block-model JSON files are also editable model sources.

The material palette is in `palette.json`: warm paper, dark wood, copper fasteners and a small redstone circuit. The paper sits at y=15.5–16 and covers the full 16×16 module. Nothing protrudes above it. Outer beams disappear along joined edges, copper splice plates appear below the shared top, and legs are conditional on external corners or exposed straight boundaries. All geometry stays inside the block.

`asset-reference.png` is a software authoring preview rendered from the same multipart JSON, including a single module, a 2×2 surface and an L. It is not a Minecraft runtime screenshot. Runtime evidence is recorded separately in `VALIDATION_STATUS.md`.

The generator validates every resource JSON, PNG signature, texture reference, geometry bounds and all sixteen connection states, then records resource hashes in `resource-sha256.json`.

Recipes and loot use singular modern resource folders (`recipe`, `loot_table`, `advancement`). The client item definition in `items/desk.json` points to the complete 3D inventory model. Loot copies the block entity's `minecraft:custom_data` component onto the dropped desk, preserving its document identity and projection.

The loot format was checked against Mojang's actual Minecraft 26.3 client resources: it uses a singular `condition` and `modifier`, both discriminated by `type`. The recipe unlock criterion uses `recipes`. Older resource formats using `conditions`/`functions` or `recipe` are intentionally not used. Vanilla `oak_fence` multipart and `crafting_table` client-item definitions confirmed the model formats, and the GUI atlas automatically includes `textures/gui/sprites` from every namespace.

The desk is a redstone scribe's bench: copper carries the pulse and paper keeps the thought. Three paper sheets form the top; copper, redstone and any three planks build the bench. All creative tools live in the editor, so no extra decorative tool items are required.
